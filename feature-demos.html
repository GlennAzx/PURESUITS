Feature demos

Four things you asked to see before deciding. Each is built against the real schedule in src/data/schedule.js — the times below are computed, not drawn.

#5 — Weekly agenda strip

A fixed Monday–Sunday row. The carousel answers “what is next”; this answers “what does my week look like”. It sits under the hero, reuses the same three events, and marks today. Colour is the category: red PvP, green PvE, orange Social.

#8 — “Next up” chip in the nav handle

The nav handle is on screen on every page. The chip puts the next event and a live countdown there, so the schedule is not trapped on Home. It turns red while an event is running.
